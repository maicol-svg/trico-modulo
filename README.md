# Modulo TRICO-AI

Pagina compilata del modulo che il cliente compila sul tablet dello studio o sul proprio telefono.
Le risposte vengono cifrate nel browser con la chiave pubblica del computer dello studio
(sealed box di libsodium) prima di partire: il server riceve solo dati illeggibili.

Non contiene dati. Si apre solo da un link d'invito creato dal programma TRICO-AI.
